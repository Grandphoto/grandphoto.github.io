## 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈 |
| `family.html` | 가족사진 (대표 촬영) |
| `id-photo.html` | 증명·여권사진 |
| `profile.html` | 프로필사진 |
| `special.html` | 장수사진 · 사진복원 |
| `gallery.html` | 갤러리 |
| `price.html` | 가격안내 |
| `location.html` | 오시는 길 · 예약 문의 |

## 자주 고치는 곳

- **전화번호·주소·영업시간·카카오톡 주소**: `js/site.js` 맨 위 `SHOP` 부분
- **사진 추가**: `images` 폴더에 사진을 넣고 `gallery.html` 안내 문구대로 한 줄 추가
- **색상**: `css/style.css` 맨 위 `:root` 부분
